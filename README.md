## ⚡ Quick Start

### Installation & Usage
1. Install [Windhawk](https://windhawk.net/).
2. Install the target official mod (e.g., `windows-11-taskbar-styler`, `windows-11-start-menu-styler`, or `windows-11-notification-center-styler`).
3. Import the corresponding verified YAML configuration from `projects/command-center/`.

### Validation Gate
```powershell
pwsh -NoProfile -File tools/Test-WindhawkStyles.ps1
```
